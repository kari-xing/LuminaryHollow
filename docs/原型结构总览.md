## 3. 关键配置（backend/.env）

| 配置 | 值 | 说明 |
| ---- | ---- | ---- |
| LLM_PROVIDER | openai | DeepSeek 云端对话 |
| LLM_BASE_URL | https://api.deepseek.com | OpenAI 兼容 SSE 流式 |
| LLM_MODEL | deepseek-v4-flash | 可换 deepseek-v4-pro |
| EMBED_BASE_URL | http://localhost:11434 | 向量化固定走本地 Ollama |
| EMBEDDING_MODEL | bge-m3 | |
| CHROMA_PORT | 8002 | 独立 hollow-chromadb 容器 |

> ⚠️ 系统代理陷阱：所有本地请求已 `trust_env=False` + `NO_PROXY`，避免被 Clash 劫持导致 503。

## 4. 启动方式

```bash
# 后端（backend/ 目录）
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8012

# 前端（frontend/ 目录）
npm install
npm run dev        # http://localhost:5173

# 数据库迁移（可选，应用启动时会自动建表）
alembic upgrade head

# 一键容器化部署（根目录）
docker compose up -d
```

## 5. API 一览（18 个 REST + 1 WebSocket）

- 认证：register / login / refresh / logout
- 用户：me / me/profile（GET / PUT）
- 会话：GET/POST /api/sessions、GET /api/sessions/{id}
- 记忆：GET/DELETE /api/memories、DELETE /api/memories
- 看板：heatmap / trend / timeline / wordcloud
- 日程：schedule CRUD + /schedule/stats（今日/本周完成率、近 N 天、时段热力图）
- 周报：weekly/latest / weekly
- 导出：/api/export（ZIP）
- 实时：`/ws/chat/{session_id}`（user_message / quick_checkin / typing / stream_chunk / stream_end / quick_ok）
